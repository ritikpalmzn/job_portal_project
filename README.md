# 💼 Job Portal System

The **Job Portal System** is a robust and user-friendly web application designed to connect job seekers and recruiters. It is built using modern Java-based technologies and follows a scalable MVC architecture.

The platform allows recruiters to post jobs and manage candidates, while job seekers can search, apply, and save jobs efficiently.

---

## 🛠️ Technologies Used

- **Java 21** – Core backend programming language
- **Spring Boot 3** – Application framework for rapid development
- **Spring MVC** – Web architecture (Model-View-Controller)
- **Thymeleaf** – Server-side template engine
- **Spring Security** – Authentication & Authorization
- **JPA (Hibernate)** – ORM for database handling
- **MySQL** – Database management system
- **Lombok** – Reduces boilerplate code
- **Bootstrap** – Responsive UI design

---

## ⚙️ Tools & Environment

- **IDE**: IntelliJ IDEA
- **Build Tool**: Maven
- **Version Control**: Git & GitHub
